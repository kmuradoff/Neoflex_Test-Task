# Микросервис "Калькулятор отпускных"

REST-сервис для расчета суммы отпускных выплат согласно правилам расчета в РФ.

---

## Основные возможности

* **Базовый расчет**  
  Расчет по среднему заработку за 12 месяцев и количеству дней отпуска
* **Расчет с учетом выходных и праздников**  
  Точный расчет, если указаны конкретные даты отпуска
* **Валидация запроса**  
  Проверка корректности входных данных

---

## API

### Метод
`POST /calculate`

### Тело запроса
```json  
{
  "totalIncome": "число",
  "vacationDays": "целое_число",
  "vacationDates": ["массив_дат"]
}
```  

| Поле          | Тип          | Формат       | Ограничения            | Описание                |  
|---------------|--------------|--------------|------------------------|-------------------------|  
| totalIncome   | BigDecimal   | Строка       | @NotNull, @Positive    | Средняя зарплата за 12 месяцев |  
| vacationDays  | Integer      | Число        | @Min(1), @Max(60)      | Общее количество дней отпуска |  
| vacationDates | Set\<LocalDate> | Дата (YYYY-MM-DD) | Опционально | Конкретные даты отпуска |  

### Ответ
```json  
{
  "vacationPay": "рассчитанная_сумма"
}
```  

---

## Примеры запросов

### Базовый расчет
```bash  
curl -X POST http://localhost:8080/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "totalIncome": "150000.00",
    "vacationDays": 28
  }'  
```  

### Расчет с датами отпуска
```bash  
curl -X POST http://localhost:8080/calculate \
  -H "Content-Type: application/json" \
  -d '{
    "totalIncome": "150000.00",
    "vacationDates": [
      "2024-01-01",
      "2024-01-02",
      "2024-01-08",
      "2024-02-23"
    ]
  }'  
```  

### Пример ответа
```json  
{
  "vacationPay": "14250.75"
}
```  

---

## Правила расчета

1. **При указании vacationDates**:
    * Исключаются выходные (суббота, воскресенье)
    * Исключаются официальные праздники РФ
    * Учитываются только рабочие дни из списка

2. **Без указания дат**:
    * Формула: `(totalIncome / 12 / 29.3) * vacationDays`
    * 29.3 — среднее количество дней в месяце
